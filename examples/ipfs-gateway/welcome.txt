fungOS / Mycelium IPFS gateway

This document is served by Agora's private Kubo node through a read-only HTTPS
content gateway. Its CID identifies these exact bytes, independently of the
gateway hostname.

Only GET and HEAD under /ipfs/ are exposed. The Kubo administration API is not
published. This first deployment uses existing tailnet HTTPS access; it does
not install Tailscale as a requirement of Mycelium or enable public ingress.
