# Security policy

Mycelium manages network equipment and can issue access credentials. Please do
not publish exploitable security reports in a public issue.

Report vulnerabilities privately through GitHub's **Security → Report a
vulnerability** flow for this repository. Include the affected commit, a minimal
reproduction, impact, and whether the issue requires `--write` or works through
a read-only path.

The project is currently pre-1.0. Security fixes target the latest `master`;
there is not yet a maintained release branch matrix.
